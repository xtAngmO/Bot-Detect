# Phone Remote — คุมมือถือ Android จากคอม/แมค

ดูจอมือถือ Android บนคอมพิวเตอร์ (Windows หรือ macOS) แล้วสั่งงานด้วยเมาส์+คีย์บอร์ด
หลักการเดียวกับ **phone mirroring** — สะท้อนจอ + ควบคุมอุปกรณ์ของตัวเอง (ต่างกับ iPhone Mirroring
ของ Apple ตรงที่ตัวนี้ใช้กับ **Android** ได้ และรันบนทั้ง Windows และ Mac)

ทำงานโดยฝัง [scrcpy-server](https://github.com/Genymobile/scrcpy) v4.1 (open source) ไว้บนมือถือชั่วคราว
ผ่าน `adb` แล้วรับสตรีม H.264 มาถอดด้วย PyAV — ปิดโปรแกรมเมื่อไหร่ server ลบตัวเองทิ้งเสมอ

## ติดตั้ง

```bash
pip install -r requirements.txt      # PySide6 + av (PyAV)
```

ต้องมี **adb** (Android SDK Platform-Tools) ในเครื่อง — โปรแกรมหาให้อัตโนมัติจาก PATH และตำแหน่งมาตรฐาน:
- Windows: `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`
- macOS: `~/Library/Android/sdk/platform-tools/adb` หรือ `brew install android-platform-tools`

`bin/scrcpy-server-v4.1` (~730 KB) โปรแกรมดาวน์โหลดจาก GitHub release ให้เองตอนใช้ครั้งแรก แล้วตรวจ
SHA256 ทุกครั้งก่อนส่งขึ้นมือถือ (ไม่ต้องเก็บลง git)

## รัน

```bash
python main.py
```

## วิธีเชื่อมต่อ

| แบบ | ทำยังไง |
|---|---|
| **USB** | เปิด USB debugging บนมือถือ เสียบสาย → เครื่องโผล่ในรายการขั้น ③ กด "เริ่มควบคุม" |
| **Wi‑Fi วงเดียวกัน** | มือถือเปิด Wireless debugging → ใส่ IP + พอร์ตในโปรแกรม |
| **ข้ามเน็ต (คนละที่)** | ลง **Tailscale** ทั้งมือถือและคอม ล็อกอินบัญชีเดียวกัน → ใช้ IP `100.x.x.x` ของมือถือ |

### ต่อไร้สายครั้งแรก (จับคู่)
บนมือถือ: **ตั้งค่า › ตัวเลือกนักพัฒนา › การแก้ไขข้อบกพร่องแบบไร้สาย (Wireless debugging)**
1. **① จับคู่**: แตะ "จับคู่อุปกรณ์ด้วยรหัสการจับคู่" → เอาพอร์ต + รหัส 6 หลักมาใส่ช่องขั้น ① กด "จับคู่" (ทำครั้งเดียว)
2. **② เชื่อมต่อ**: เอาพอร์ตจากหัวข้อ "IP address & Port" (คนละพอร์ตกับตอนจับคู่ และ**เปลี่ยนทุกครั้งที่เปิดสวิตช์ใหม่**) มาใส่ขั้น ② กด "เชื่อมต่อ"
3. **③** เลือกเครื่อง เลือกความละเอียด กด "เริ่มควบคุม"

โปรแกรมจำ IP/พอร์ตล่าสุดไว้ เปิดครั้งหน้าจะลองต่อให้เอง

## ปุ่มควบคุมในหน้าต่าง

เมาส์บนภาพ:
- **คลิกซ้าย** = แตะ · **ลาก** = ปัด/เลื่อน · **Ctrl+ลาก** = ถ่างสองนิ้ว (ซูม) · **ล้อเมาส์** = เลื่อน
- **คลิกขวา** = ย้อนกลับ · **คลิกกลาง** = หน้าแรก

คีย์บอร์ด: พิมพ์ได้เลย (ภาษาไทยส่งผ่าน clipboard อัตโนมัติ) · **Esc** = ย้อนกลับ · **Ctrl+V** = วางข้อความจากคอม

แถบปุ่มด้านขวา: ย้อนกลับ · หน้าแรก · สลับแอป · เพิ่ม/ลดเสียง · Power · แผงแจ้งเตือน · หมุนจอ ·
ปิดจอมือถือ (แต่คอมยังคุมต่อได้) · วางข้อความ · แคปหน้าจอ · เชื่อมต่อใหม่

## เทสต์

```bash
python tests/test_protocol.py                       # เทียบ byte โปรโตคอลกับ scrcpy v4.1

```

## โครงไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `protocol.py` | แปลงคำสั่ง↔byte + อ่าน header สตรีม (ลอกจากซอร์ส scrcpy v4.1 ตรงตัว) |
| `adb.py` | ห่อ `adb` + อ่านรายชื่อเครื่อง Tailscale (cross-platform) |
| `scrcpy_server.py` | ดาวน์โหลด/ตรวจ + push + เปิด/ปิด scrcpy-server บนมือถือ |
| `stream.py` | thread ถอดวิดีโอ (PyAV) + ช่องส่งคำสั่งควบคุม |
| `window.py` | หน้าต่างควบคุม: จอ + แถบปุ่ม + แปลงเมาส์/คีย์ |
| `connect_dialog.py` | หน้าจอแรก: จับคู่/เชื่อมต่อ/เลือกเครื่อง |
| `keymap.py` `icons.py` `settings.py` `ui_common.py` | ตารางคีย์ · ไอคอนลายเส้น · ค่าที่จำไว้ · ธีม+ตัวรัน async |

## macOS

โค้ดรันบน macOS ได้ (PySide6 + PyAV + adb ข้ามแพลตฟอร์ม) จุดที่ต่างจาก Windows โปรแกรมจัดการให้แล้ว:
หา `adb`/`tailscale` จากตำแหน่งของ macOS, ไม่มีการซ่อนหน้าต่าง console (เป็นของ Windows เท่านั้น)
ครั้งแรกที่รัน macOS อาจถามสิทธิ์เข้าถึงเครือข่าย — กดอนุญาต
